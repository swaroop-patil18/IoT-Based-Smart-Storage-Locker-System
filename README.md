# IoT-Based-Smart-Storage-Locker-System
Smart Locker System using Android, Node.js, and ESP32 for secure automated storage. Users can view availability, reserve lockers, pay via Razorpay, and receive OTPs for access. ESP32 verifies OTP and unlocks lockers. Features include real-time status updates, timers, auto reset, and partial or full pickup support. Ensures secure and efficient usage
